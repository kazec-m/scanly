# Scanly

家庭や学校から届く書類を、スマホで撮影するだけで自動管理できるアプリです。OpenAIのマルチモーダル機能で書類の種類・期限を自動解析し、家族グループのカレンダーへ即座に登録・通知します。

> プログラミングスクールのチーム開発課題として、4人チームで制作しました。

## できること

- 書類を撮影するだけで、AIが種類・期限を自動解析
- 解析結果はその場で確認・修正してから登録
- 登録するとグループ全員のカレンダーに即時反映、他のメンバーに通知
- 提出・支払いが終わった書類は「済スタンプ」で管理
- 期限のN日前に自動でリマインドメールを送信

## 技術スタック

| レイヤー | 技術 |
|---|---|
| フロントエンド | Next.js (App Router) / TypeScript / Tailwind CSS |
| バックエンド | FastAPI (Python) / SQLAlchemy / Alembic |
| 非同期タスク | Celery (Worker / Beat) |
| データベース | PostgreSQL |
| キャッシュ・キュー | Redis |
| 認証 | Firebase Auth |
| 外部API | OpenAI API / SendGrid / Stripe / Cloudinary |
| インフラ | Docker Compose(開発) / Vercel・Render(本番) |

## 私(kazec-m)の役割: 認証・開発環境構築担当

バックエンドの中でも、認証まわりと開発環境の土台づくりを中心に担当しました。

- **Firebase認証のJWT検証**を、データベースに依存せず単体で動作確認できる設計で実装(`deps.py`)
- 各メンバーの実装で挙動が割れていた「未登録ユーザーへの対応」を、ログインの冪等性を作り込む過程で発見し、コンフリクトを避けながら統一方針をチームに提案
- **チーム全体の開発環境(docker-compose)を主導して構築**。ホットリロード対応、ヘルスチェックによる起動順序制御、Adminer/Redis Commanderなど開発用ツールの整備を担当し、最後まで運用
- ペアプログラミングに挑戦し、初めてのRenderへの本番デプロイをサポート役を担当した(2時間で完了)
